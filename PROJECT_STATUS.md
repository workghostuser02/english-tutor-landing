# Статус проекта

## Выполнено

- разобрано открытое задание;
- выбран самостоятельный визуальный стиль;
- подготовлены структура, тексты, HTML, CSS и JavaScript;
- добавлена авторская демонстрационная иллюстрация;
- предусмотрены честные состояния для отсутствующих отзывов, цен и контактов.

## Проверено

- локальная проверка на 320, 375, 390, 768 и 1440 px — без горизонтальной прокрутки;
- меню, якорные ссылки, клавиатурный фокус, FAQ и валидация формы работают;
- изображения загружаются, ошибок консоли и битых внутренних ссылок нет;
- подготовлены и визуально проверены кадры 1440×900 и 390×844.
