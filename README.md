# Clear Step English — учебная концепция

Адаптивный одностраничный сайт частного преподавателя английского языка. Создан как учебная концепция по мотивам открытого задания на FL.ru и не является работой для реального заказчика.

## Что реализовано

- семантическая HTML5-разметка;
- самостоятельный визуальный стиль без фреймворков;
- адаптация от 320 px;
- доступная навигация, видимый фокус и FAQ на `details`;
- демонстрационная форма с проверкой обязательных полей;
- честные блоки для цены, отзывов и контактов без вымышленных данных;
- локальная оптимизированная иллюстрация.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```powershell
python -m http.server 8004
```

Форма не отправляет персональные данные. Для реального проекта потребуется подключить серверный обработчик и подтверждённые контакты преподавателя.
